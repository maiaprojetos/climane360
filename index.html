Fontes e metodologia

Limites municipais: malha municipal distribuída para o navegador. Meteorologia e radiação solar: Open-Meteo. Pressão local: pressão atmosférica na superfície do município. Pressão ao nível do mar: pressão atmosférica reduzida ao nível médio do mar. Chuva 2026: soma diária desde 01/01/2026. Ng: dados municipais publicados em ng-brasil-mapas, conforme NBR 5419-2:2026 (Anexo F).

🧭 Pressões atmosféricas

A pressão local representa a pressão atmosférica na superfície/elevação do município. A pressão ao nível do mar é a pressão reduzida ao nível médio do mar. Ambas são apresentadas em hPa.

⚡ Ng municipal — fonte indicada

O valor de Ng é obtido diretamente do arquivo ng_dados.json publicado pelo projeto Ng por Município, usando o código IBGE do município. O campo principal utilizado é ng_nbr5419_2026.

Publicação

V41 — Este projeto é estático e pode ser publicado no GitHub Pages, Netlify ou Vercel. As consultas meteorológicas são feitas diretamente à API do Open-Meteo no navegador.
